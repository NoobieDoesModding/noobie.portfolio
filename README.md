# NoobieDoesModding Portfolio

Personal portfolio for NoobieDoesModding, built with HTML, CSS, and vanilla JavaScript.

**Live site:** [noobiedoesmodding.github.io/noobie.portfolio](https://noobiedoesmodding.github.io/noobie.portfolio/)

## Features

- Discord status and Rich Presence
- About and future studies sections
- Social and project links
- PC component list

## Run locally

Open `index.html` in a browser. Profile details, links, and PC components can be customized in `script.js`.
